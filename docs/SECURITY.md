# ForgeRelay 安全说明（SECURITY.md，M5 交付，需求 §8）

面向安全评审与部署加固。

## 1. 认证（FR-AUTH-01..03）

- Bearer token（`fr_` + 64 hex）：数据库仅存 SHA-256 摘要，**明文仅在创建响应中显示一次**。
- 令牌可挂过期时间（TTL）与主动撤销（TOKEN_REVOKE）；校验同时检查用户禁用状态。
- 随机数来自系统加密 API（SEC-01：Linux OpenSSL RAND / Windows CNG，D-13），不自研。

## 2. 授权（§2.1 角色矩阵，FR-AUTH-04）

| 操作 | Reader | Publisher | Admin |
|---|---|---|---|
| 下载 / 查询 / 状态 | ✓ | ✓ | ✓ |
| 上传 / 提交 / 终止本人会话 | ✗ | ✓ | ✓ |
| 删除制品 | ✗ | 仅本人制品 | ✓ |
| GC / 用户 / 令牌 / 会话管理 | ✗ | ✗ | ✓ |

每个请求在业务处理前完成角色检查（FR-AUTH-04）；错误码区分
`FR_E_UNAUTHENTICATED`（未认证）与 `FR_E_FORBIDDEN`（权限不足）。

## 3. 速率限制与拒绝服务缓解（FR-AUTH-05、SEC-08）

- 连接内连续认证失败 ≥5 次：服务端主动断开。
- 来源 IP 60 秒窗口内 ≥20 次失败：封禁 60 秒（单调时钟计时，D-26 #4）。
- 消息负载 ≤8 MiB、连接数/工作队列/单用户会话均有上限（§7.3），超限回 busy 或拒绝。
- QUERY 位图、GET 分片状态均设协议上限，防止恶意声明的内存膨胀（审计 #5）。

## 4. 传输安全（SEC-01/02，D-20）

- TLS 1.3（OpenSSL 3.x，最低兼容 1.2）；服务端加载证书链与私钥。
- 客户端校验服务端证书与主机名（SNI + `SSL_set1_host`），不允许静默降级。
- 仅回环监听允许关闭 TLS（§5.1）；Windows 开发分支无 TLS（明文回环）。

## 5. 输入与路径安全（SEC-05/06、FR-STO-02）

- 制品标识白名单校验（FR-ART-02/03），拒绝绝对路径、`..`、NUL、控制字符。
- 块文件路径仅由 SHA-256 摘要生成（两段十六进制目录），用户输入不参与路径拼接。
- 不使用 `system`/`popen`；日志与错误不含令牌、密钥、内部路径或 SQL（SEC-07/PROTO-06）。

## 6. 文件与运行权限（SEC-03/04）

- 专用系统用户 `forgerelay` 运行（见 deploy/forgerelayd.service），不使用 root。
- 数据/日志目录 0750，块文件 0600，目录 0700；私钥 0600 且仅属主可读。
- systemd 沙箱：NoNewPrivileges、ProtectSystem=strict、PrivateTmp。

## 7. 数据完整性（FR-STO-05、D-15）

- 块文件头含 CRC32；整块读取校验，损坏块返回错误。
- 发布为单事务：元数据 + 清单原子提交，不存在缺块的已发布制品。
- 内容寻址（路径即摘要）天然防篡改错位；异常退出由启动恢复处理（FR-STO-06）。

## 8. 泄露应急

令牌疑似泄露：`frctl token revoke <id>` 立即撤销（撤销即时生效，校验路径实时查询）。
必要时禁用对应用户（USER_DISABLE），其所有令牌校验将返回"用户已禁用"。
